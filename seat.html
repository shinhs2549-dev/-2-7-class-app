학급 자리 배치

명단 입력 → 좌석 설정 → 배정 → 인쇄

1. 학생 명단

번호 / 이름 / 성별 순으로 붙여넣거나(탭 또는 쉼표 구분), 엑셀 파일을 업로드하세요.

0명
번호이름성별고정 좌석 (우선권 등)

시상 등으로 자리를 미리 정해준 학생은 "고정 좌석"에서 자리를 골라두면, 배정 시 그 학생은 지정한 자리로 고정되고 나머지 학생만 무작위로 배정됩니다.

2. 좌석 설정

책상(2인 1조)을 클릭하면 무관 → 남 전용 → 여 전용 순으로 바뀝니다. 빈 자리는 배정 시 무작위로 정해집니다.

무관 남 전용 여 전용

교사 전용 설정

이 창은 Ctrl+Alt+T 또는 맨 위 제목을 1.5초 안에 5번 탭(클릭)해야 열리며, 학생 화면·결과·인쇄물 어디에도 나타나지 않습니다.

두 학생을 절대 짝(옆자리)으로 배정하지 않도록 지정합니다.

↔

3. 자리 배정

번호 1번부터 순서대로, 미리 무작위로 섞인 좌석에 배정합니다. 배정 버튼을 누르면 큰 화면으로 한 명씩 순서대로 자리가 채워집니다.

4. 구글 드라이브 자동 저장 (선택)

전자칠판에서 배정하면 결과 이미지(학생용·교사용)가 자동으로 구글 드라이브 "자리배치_결과" 폴더에 저장됩니다. 교무실 컴퓨터에서는 그 폴더를 열어 바로 확인하면 됩니다. Apps Script 배포 후 나온 웹 앱 주소(…/exec)를 넣어주세요.
